# Чистоград — сервис контроля чистоты города

Веб-сервис, в котором жители отмечают несанкционированные свалки на интерактивной карте OpenStreetMap, а коммунальные службы и администраторы получают заявки, берут их в работу и отчитываются об устранении, меняя статусы. Весь жизненный цикл обращения — от клика по карте до фотоотчёта — прозрачен и виден каждому участнику.

---

## Возможности

### Житель
- Отмечает свалку кликом по карте — точка получает номер (`ЧГ-112`), категорию и автоматически определённый район.
- Описывает проблему, добавляет ориентир, отслеживает статус своей заявки.
- Оставляет комментарии и может отозвать собственную заявку, пока она не взята в работу.

### Коммунальная служба
- Видит очередь новых заявок и берёт их в работу от имени своей организации.
- Выполняет уборку и сдаёт отчёт об устранении: примечание о проведённых работах + фотофиксация «после».

### Администратор
- Контролирует все заявки: назначает и переназначает исполнителей, отклоняет необоснованные обращения с указанием причины, возвращает отклонённые в работу.

### Общие возможности
- **Интерактивная карта OpenStreetMap (Leaflet)**: реальные тайлы OSM, подписи районов, панорамирование, зум колесом и кнопками, масштабная линейка, hover-тултипы маркеров.
- **Статусы заявок**: `Новая → В работе → Устранена` / `Отклонена` — с таймлайном каждого перехода, временем и исполнителем.
- **Фильтры**: по статусам (в т.ч. прямо на карте), типу отходов (6 категорий), району.
- **Реестр заявок**: карточки с цветовой кодировкой статуса и экспортом в CSV.
- **Дашборд**: KPI с анимацией счётчиков, донат-диаграмма статусов, недельная динамика, разбивка по районам и типам, рейтинг служб.
- **Лента событий**: бегущая строка последних действий по всем заявкам в реальном времени.
- **Фотофиксация «до/после»** в карточке заявки, координаты и ссылка «Открыть в OSM» на openstreetmap.org.
- Данные сохраняются в `localStorage` браузера — заявки переживают перезагрузку страницы.

## Технологический стек

| Слой | Технология |
|---|---|
| Фреймворк | React 18 + TypeScript |
| Сборка | Vite 6 |
| Стили | Tailwind CSS 4 |
| Карта | Leaflet 1.9 + тайлы OpenStreetMap |
| Шрифты | Unbounded (акцидентный) · Golos Text (текстовый) · JetBrains Mono (цифры, номера, координаты) |
| Хранение | localStorage (демо-режим, без бэкенда) |

## Быстрый старт

Требуется **Node.js ≥ 18**.

```bash
# установка зависимостей
npm install

# запуск в режиме разработки
npm run dev          # http://localhost:5173

# проверка типов
npm run typecheck

# производственная сборка
npm run build        # результат в dist/
```

> Для загрузки тайлов OpenStreetMap нужен доступ в интернет. Приложение корректно работает офлайн по данным, но подложка карты не отобразится.

## Модель данных

```ts
interface Report {
  id: string;
  num: number;            // номер обращения, ЧГ-112
  lat: number; lng: number; // координаты на карте (WGS-84)
  district: string;       // район — определяется по ближайшему центру
  address: string;        // ориентир от жителя
  category: CategoryId;   // house | construction | tires | hazard | green | other
  description: string;
  status: Status;         // new | work | done | rejected
  author: string;
  assignee?: string;      // организация-исполнитель
  photoBefore?: string;   // фотофиксация «до»
  photoAfter?: string;    // фотоотчёт «после»
  resolveNote?: string;   // отчёт службы об устранении
  rejectReason?: string;
  createdAt / updatedAt / resolvedAt: number;
  timeline: TimelineEvent[];  // журнал переходов статусов
  comments: CommentT[];       // обсуждение заявки
}
```

## Карта OpenStreetMap

- **Тайлы**: `https://tile.openstreetmap.org/{z}/{x}/{y}.png`.
- **Атрибуция** «© участники OpenStreetMap» обязательна и отображается на карте (лицензия ODbL, см. [openstreetmap.org/copyright](https://www.openstreetmap.org/copyright)).
- **Демо-полигон**: Казань (центр `[55.7961, 49.1088]`, стартовый зум 12) с реальными районами: Вахитовский, Ново-Савиновский, Московский, Кировский, Приволжский, Советский. Чтобы развернуть сервис на другом городе, измените `CITY_CENTER`, `CITY_ZOOM`, `CITY_NAME` и список `DISTRICTS` в `src/data.ts`, а также координаты сид-заявок.
- **Слои**: тайловая подложка → подписи районов (divIcon) → маршруты патрулей (polyline с анимацией пунктира) → маркеры заявок (divIcon с глифом категории и цветом статуса).

## Демо-режим и сброс данных

- Роли «Житель / Служба / Администратор» переключаются в шапке — это демонстрация разделения прав, а не реальная авторизация.
- Заявки хранятся в `localStorage` под ключом `chistograd.reports.v2`. Чтобы вернуться к исходным демо-данным, выполните в консоли браузера:

```js
localStorage.removeItem("chistograd.reports.v2");
location.reload();
```

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Esc` | закрыть форму / выйти из режима «Сообщить о свалке» / закрыть карточку заявки |

## Ограничения и направления развития

- Нет серверной части: данные локальные, фотофиксация — демо-изображения. Для продакшена потребуется API (регистрация, права доступа, загрузка фото), а также Nominatim-геокодинг для автоматического определения адреса по координатам.
- Переход на реальные административные границы районов (GeoJSON-полигоны вместо ближайших центров).
- Уведомления участников, SLA-таймеры по заявкам, мобильное приложение для экипажей.
